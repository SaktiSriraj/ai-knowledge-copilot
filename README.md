# 🧠 AI Knowledge Copilot

A multi-user AI system that lets users upload documents and interact with them using natural language.

It processes documents into semantic knowledge and allows users to:

- Upload PDFs or text files  
- Ask questions about their documents  
- Get context-aware AI-generated answers  
- Receive fast, relevant responses using retrieval-based reasoning  

Each user’s data is isolated, making it a personalized knowledge assistant.

---

Built as a production-oriented MVP for scalable AI applications.
